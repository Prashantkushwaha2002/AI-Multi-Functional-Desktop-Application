# AI-Multi-Functional-Desktop-Application
🚀 Overview

A modular AI-powered desktop application integrating:

Computer Vision (Face Detection)

Voice Command Execution

AWS Cloud Automation (EC2 control)

AI-enhanced Web Search (LangChain + SERP API)

Chrome-based Web Automation

Tkinter GUI Interface

🧠 Architecture

The system follows a modular architecture:

video_module – Computer Vision processing

voice_module – Speech Recognition pipeline

aws_module – Cloud automation via Boto3

ai_module – LangChain-based intelligent web search

web_module – Browser automation

main.py – Central GUI controller

🔧 Tech Stack

Python 3.11+

OpenCV

SpeechRecognition

Boto3 (AWS SDK)

LangChain

SERP API

Tkinter
